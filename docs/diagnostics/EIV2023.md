# EIV2023 — UnmappedElement (ZUGFeRD 1.0)

| | |
|---|---|
| **Category** | `UnmappedElement` |
| **Default severity** | `Info` |
| **Fallback** | The element is kept verbatim in `ExtensionData`, anchored where it sat |

## What it means

A ZUGFeRD 1.0 document carried an element the canonical model does not describe. It is the ZUGFeRD 1.0
counterpart of [EIV2020](EIV2020.md), under its own code so that a caller reading an archive can tell 2013
content apart from anything else.

**This one matters more than its siblings.** Reading ZUGFeRD 1.0 is something you do to an archive, and an
archive is read to find out what a document said — including the parts EN 16931 never had a term for. The
German `Bankleitzahl` is the clearest case: a sort code that was on every 2013 German invoice, that the
semantic model has no field for, and that somebody auditing an old payment may be looking for precisely.

## Example

```xml
<ram:PayeeSpecifiedCreditorFinancialInstitution>
  <ram:BICID>GENODE61AAA</ram:BICID>
  <ram:GermanBankleitzahlID>66650085</ram:GermanBankleitzahlID>
  <ram:Name>Volksbank</ram:Name>
</ram:PayeeSpecifiedCreditorFinancialInstitution>
```

```
EIV2023  Info  UnmappedElement  Element 'GermanBankleitzahlID' is not part of the canonical model and was
    kept as extension data. at /rsm:CrossIndustryDocument/rsm:SpecifiedSupplyChainTradeTransaction/
    ram:ApplicableSupplyChainTradeSettlement/ram:SpecifiedTradeSettlementPaymentMeans/
    ram:PayeeSpecifiedCreditorFinancialInstitution/ram:GermanBankleitzahlID (line 96)
    fallback  kept verbatim as extension data
```

## Reaching the content

`Extensions()` walks the whole invoice, so an archive can be searched without knowing which node the content
hangs off:

```csharp
ExtensionElement? blz = invoice.Extensions()
    .FirstOrDefault(element => element.LocalName == "GermanBankleitzahlID");
```

## When migrating forward

These are what `EInvoicing.Convert` reports as conversion losses. A migration that matters should read the
list rather than assume it is empty: what a 2013 document said and what a 2019 one can say are not the same
set.
