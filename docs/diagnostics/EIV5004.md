# EIV5004 — MalformedXml (Order-X)

| | |
|---|---|
| **Category** | `Safety` |
| **Default severity** | `Fatal` |
| **Fallback** | None. No document is produced. |

## What it means

The bytes handed to the Order-X reader are not well-formed XML, or they broke a limit that exists to stop
hostile input. It is [EIV5001](EIV5001.md) for Order-X, under its own code so a caller can tell which reader
refused.

There is nothing to fall back to: a reader cannot map a document it cannot parse. `ParseResult.IsUsable` is
false and `Value` is null.

## Example

```
EIV5004  Fatal  Safety  The document is not well-formed XML: Unexpected end of file has occurred.
    at line 812, position 1
```

## Common causes

| What happened | What to do |
|---|---|
| Truncated transfer | Re-fetch the document; check the sender's transport |
| A DTD or external entity | The document is trying to reach outside itself. Treat it as hostile. |
| Document larger than the limit | Raise `DocumentLimits.MaxDocumentCharacters` **only** if you trust the source |
