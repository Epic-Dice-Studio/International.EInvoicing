# EIV2021 — UnmappedElement (Order-X)

| | |
|---|---|
| **Category** | `UnmappedElement` |
| **Default severity** | `Info` |
| **Fallback** | The element is kept verbatim in `ExtensionData`, anchored where it sat, and written back unchanged |

## What it means

An Order-X document carried an element the canonical model does not describe. It is the Order-X counterpart
of [EIV2020](EIV2020.md), reported under its own code because the two syntaxes are read by different readers
and a caller filtering on one should not silently catch the other.

Nothing was dropped, and — unlike a plain "kept somewhere" — nothing was moved: the element remembers which
element it sat in and which mapped sibling it followed, so it goes back exactly there. The Cross Industry
Order's element order is normative, so this is the difference between a document a receiver accepts and one
it rejects.

## Example

```xml
<ram:SpecifiedTradeProduct>
  <ram:Name>Un article</ram:Name>
  <acme:Grade xmlns:acme="urn:acme:national:1.0">premier</acme:Grade>
  <ram:OriginTradeCountry><ram:ID>FR</ram:ID></ram:OriginTradeCountry>
</ram:SpecifiedTradeProduct>
```

```
EIV2021  Info  UnmappedElement  Element 'Grade' is not part of the canonical model and was kept as
    extension data. at /rsm:SCRDMCCBDACIOMessageStructure/rsm:SupplyChainTradeTransaction/
    ram:IncludedSupplyChainTradeLineItem/ram:SpecifiedTradeProduct/acme:Grade (line 58)
    fallback  kept verbatim as extension data
```

Written back, `acme:Grade` returns inside `ram:SpecifiedTradeProduct`, after `ram:Name` — not at the end of
the product and not at the end of the document.

## Reaching the content

```csharp
foreach (ExtensionElement element in order.Lines[0].Item!.Extensions)
{
    string xml = element.Xml;              // the element exactly as it arrived
    string? after = element.PrecedingSibling;   // the mapped sibling it followed
    string? inside = element.ParentName;        // the element it sat in
}
```

## When to worry

One of these on a term you expected to be modelled means the model has a gap worth reporting. A burst of
them from one sender usually means an Order-X EXTENDED document read against a narrower profile.

```csharp
services.AddEInvoicing(o => o.OnCode("EIV2021", DiagnosticAction.Escalate));
```
