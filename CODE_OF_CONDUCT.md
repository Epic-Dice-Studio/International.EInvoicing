# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and accept that contributors
come from different countries, tax regimes and levels of experience with these norms.

Unacceptable behaviour can be reported privately to the maintainers through GitHub. Reports are handled
confidentially, and maintainers who violate the code are held to the same standard as everyone else.
